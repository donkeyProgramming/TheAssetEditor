Exporting models to glTF and GLB

AssetEditor can export .rigid_model_v2, .wsmodel, and .variantmeshdefinition files. A VariantMeshDefinition is exported as one composed scene using its first renderable/default slot choices.

Export a model

  1. Load the packs containing the model and its referenced textures, skeleton, and animations.
  2. In the PackFile explorer, right-click the model file.
  3. Select Export > Advanced Export.
  4. Select Rmv_to_Gltf.
  5. Choose texture and animation options. Select the animation clips to include.
  6. Select Browse, then choose glTF (.gltf) or Binary glTF (.glb) in the save dialog.
  7. Select Export.

If a stand_idle animation is available, it is selected by default. Use Select all, Select none, or the filter box to change the selection. If the panel reports that the skeleton or animations are unavailable, load the required game or mod packs before reopening the export window.

glTF or GLB?

  • glTF writes a .gltf file with supporting image and buffer files. Keep the files together.
  • GLB embeds the standard glTF resources in one .glb file. Temporary embedded texture PNGs are removed after a successful save.

Auxiliary files made for manual workflows, such as Warhammer mask or displacement images, can remain next to a GLB because they are not standard glTF material channels.

What is exported

  • LOD0 geometry, UVs, normals, tangents, and supported material textures.
  • The effective WSModel material overrides used by AssetEditor, including when an RMV2 has a valid sibling WSModel.
  • For VMD files, nested model components, one compatible shared skeleton, and bone attachments.
  • Only the animation clips selected in the export panel.

Limitations

  • Only LOD0 and one default VMD composition are exported.
  • Total War faction tint and other custom shader effects cannot be represented exactly by standard glTF.
  • A Warhammer mask texture is exported as an auxiliary *_mask.png; it is not connected as base color or alpha.
  • A VMD component using a different skeleton from the shared skeleton is exported without skinning.
  • All referenced files must be available in the packs currently loaded by AssetEditor.

Viewing the result

Open the exported file in a glTF-capable application such as Blender or the Khronos glTF Sample Viewer. For .gltf, do not separate the main file from its sidecars.
