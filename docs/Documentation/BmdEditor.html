BMD Editor

A BMD (battle map definition) lists the things placed on a map: props, decals, VFX, lights, sounds, composite scenes and, on battle maps, buildings, capture locations and deployment zones. The BMD Editor shows a BMD in 3D, lets you edit and add the common element types, and can export a prefab as a Terry project.

Which files it opens

  • Prefabs: .bmd files, such as the ones under prefabs/.
  • Battle-map BMDs: .bin files under terrain/tiles/battle whose name contains bmd_data, bmd_nogo_data or bmd_objects_sound, or ends in _bmd.bin. Other .bin files are not BMDs and are left to their own editors.

Double-click a file in the PackFile explorer to open it. Every version used by Warhammer 3 can be opened. Files older than FASTBIN version 11 can be viewed but not saved.

The editor window

  • 3D view (left): the map contents. Props are drawn with their models; other elements are drawn as markers such as cubes, spheres, cones and outlines. Click an element to select it.
  • Components (top right): everything in the file, grouped by type with a count, for example Props (12). A referenced BMD lists the contents of the file it points to underneath it.
  • Details (bottom right): the fields of the selected element.

Editing elements

These ten types have editable fields in the Details panel: props, decals, VFX, point lights, spot lights, sounds, poly meshes, light probes, terrain holes and composite scenes. All other types are shown as read-only text.

To move an element, select it and pick a gizmo mode on the toolbar: Move, Rotate or Scale. Rotate and Scale are only enabled for types that store them:

  • Props, decals, VFX, composite scenes and newer poly meshes: move, rotate and scale.
  • Spot lights: move and rotate.
  • Point lights, light probes and older poly meshes: move only.
  • Sounds: the gizmo moves all points together; single points are edited in the Details panel.
  • Terrain holes: the gizmo moves the whole triangle; single corners are edited in the Details panel.

The last gizmo button turns the gizmo off, leaving selection only. Transform values can also be typed directly into the Details panel.

Adding elements

Use the Add menu on the toolbar. The new element is placed at the origin, selected, and can then be moved.

  • Prop and Decal: browse for a .rigid_model_v2 or .wsmodel.
  • VFX: type the effect name.
  • Sound: type the sound event name.
  • Poly mesh: type the material name.
  • Composite scene: browse for a .csc.
  • Point light, Spot light, Light probe, Terrain hole: added directly.

New props, VFX, sounds and composite scenes are not restricted to any culture. Elements cannot be deleted in the editor.

Saving

Save writes the whole file back to the editable pack, at the same path. Sections the editor does not let you edit are written back unchanged. Refresh reloads the file and discards unsaved edits.

Exporting to Terry

A .bmd prefab can be exported as a project for Terry, the Assembly Kit's map editor:

  1. Select Export on the toolbar, or right-click the .bmd in the PackFile explorer and select Export as Terry project.
  2. Choose an output folder.

This writes a .terry file and a .layer file. The entities are grouped into layers by type: Props, Decals, VFX, Light Probes, Terrain Holes, Point Lights, Polygon Meshes, Spot Lights, Sounds and Composite Scenes.

Limitations

  • Only .bmd prefabs can be exported. Battle-map .bin BMDs cannot.
  • Only the ten types listed above are exported. Buildings, capture locations, deployment zones and outlines are not.
  • BMDs referenced by the prefab are flattened into the same layer. Their culture mask is carried over to their contents, but the reference's own position is not applied.
  • Referenced BMDs must be in the packs currently loaded by AssetEditor.
